# Time Tracker

A simple time tracker to manage study hours across university modules with weekly goals and insights.

## Features

- Track time for different modules.
- Set weekly goals.
- View progress with a chart.
- Archive and unarchive weeks.
- A timer functionality.
- PWA features.

## Tech Stack

- React
- Tailwind CSS
- Chart.js

## Getting Started

1. Clone the repository.
2. Open `src/index.html` in your browser.
